# Zzz 的工作站

Windows 本地优先、离线可用的个人工作台。任务、Markdown 笔记、提示词、专注记录和个人日常管理均保存在加密本地数据库中；第三期的外部服务均为可选功能。

## 当前功能

- **任务管理**：列表、GTD（收集箱/下一步/等待/将来）、艾森豪威尔四象限、优先级、项目、标签、重复规则、截止时间和 Windows 提醒。
- **本地日历**：按月查看任务截止日与每日习惯完成情况。
- **习惯与喝水**：建立、打卡和删除习惯；记录每日喝水量并设置本机提醒。
- **笔记与附件**：Markdown 编辑和预览，附件复制到工作站数据目录后受控打开。
- **提示词模板**：分类、收藏、变量填写和一键复制。
- **专注与周报**：番茄钟、托盘后台提醒、项目/标签统计、Markdown 周报导出。
- **文件索引**：仅索引用户主动选择文件夹中的文件名、路径、类型、大小和修改时间；不读取正文、不上传文件。
- **备份恢复**：导出包含加密数据库、密钥信封和附件的 ZIP 备份；恢复会替换当前工作站数据。
- **RSS 阅读**：手动添加 HTTPS RSS/Atom 地址，支持分组、未读、收藏、搜索与后台刷新；缓存内容不保留原始 HTML。
- **邮件周报**：QQ、163、126、yeah.net 邮箱可用 SMTP 授权码向自己自动发送周报。
- **OSS 异地备份**：可选阿里云 OSS 加密备份；每天最多上传一次自动备份并保留最近 30 份。
- **更新检查**：从 GitHub Releases 检查新版，核验 SHA-256 后由你确认安装。

## 安装与升级

1. 在 GitHub Releases 下载最新的 `Zzz Workstation-x.y.z Setup.exe`。
2. 退出托盘中的旧版本，再运行安装程序。
3. 覆盖升级会保留既有工作站数据。桌面会同时提供“Zzz 的工作站”和“卸载 Zzz 的工作站”快捷方式；也可通过 Windows 设置的“已安装的应用”卸载。

首次打开时需要设置主密码。主密码不会保存到磁盘，也无法找回；请自行保管并定期导出备份。

## 使用建议

- 新任务默认进入 **收集箱**；随后在 GTD 视图中整理为下一步、等待或将来/也许。
- 任务行右侧的 `×` 可删除误建任务，删除前会二次确认。
- 文件索引只应添加工作资料目录；移除索引目录只删除索引记录，绝不删除原始文件。
- 关闭窗口会最小化到托盘，选择托盘菜单的“退出”才会停止提醒。

## 数据、安全与卸载

- 数据库、附件和设置位于 `%APPDATA%\Zzz Workstation`，业务数据使用 SQLCipher 兼容加密。
- 锁定应用或 Windows 锁屏后，数据库连接会关闭。
- 手动导出到其他位置的备份不会随卸载删除；忘记主密码后，应用数据和备份均无法恢复。
- 卸载会删除 `%APPDATA%\Zzz Workstation` 内的数据库、附件、缓存、设置和本机受保护凭据，并显示完成提示。
- 外部整合默认关闭。未配置 RSS、邮箱或 OSS 时，所有一期、二期本地功能仍可断网使用。
- 邮箱 SMTP 授权码和 OSS AccessKey 通过 Windows DPAPI 受保护保存，不进入数据库、日志、导出备份或 Git。
- OSS 只能配置私有 Bucket 的 `zzz-workstation/` 前缀；务必使用最小权限 RAM 用户，禁止使用主账号或 `AliyunOSSFullAccess`。

## 开发与验证

```powershell
npm install
npm start
npm test
npm run package
npm run make
```

- `npm test`：本地业务规则、路径安全和主密码信封测试。
- `npm run package`：生成可直接运行的 Windows 应用。
- `npm run make`：生成 Squirrel Windows 安装包。

## 发布策略

推送 `v1.2.0` 这类版本标签会触发 Windows GitHub Actions：安装依赖、运行测试与生产依赖审计、生成 `Setup.exe`、生成 SHA-256 文件并创建 GitHub Release。仓库 Actions 需要具有 `contents: write` 权限；流程使用 GitHub 内建令牌，不需要个人 PAT。
